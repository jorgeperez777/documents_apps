# documents_apps

Documentos técnicos de portafolio.

| Documento | Qué cubre |
| --- | --- |
| [`infraestructura-gcp.html`](infraestructura-gcp.html) · [PDF](infraestructura-gcp.pdf) | Infraestructura y entrega continua en Google Cloud de tres productos en producción: pipelines de Cloud Build, imágenes multietapa con verificación, migraciones fuera del despliegue, secretos, observabilidad y un entorno de staging levantado desde cero. |

El HTML es la versión que se lee en pantalla —se adapta al ancho del teléfono y
al tema claro u oscuro del sistema— y el PDF es el mismo documento con su hoja
de impresión, en A4, para adjuntar.

Los identificadores de infraestructura (proyectos, cuentas de servicio,
instancias, nombres de secretos y direcciones de servicio) se omiten a
propósito: no aportan al relato y no deben publicarse.
